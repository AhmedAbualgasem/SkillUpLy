## المتطلبات الوظيفية (Functional Requirements)

### 1. إدارة المستخدمين (User Management)
- إنشاء حساب جديد باستخدام البريد الإلكتروني أو تسجيل دخول اجتماعي عبر Google و Facebook.
- تسجيل الدخول إلى الحساب وإدارة جلسات المستخدم بأمان.
- استرجاع كلمة المرور عبر البريد الإلكتروني.
- تحديث الملف الشخصي: الاسم، الصورة، رقم الهاتف، كلمة المرور.
- تحديد نوع الحساب (طالب، مدرب، مشرف) والتحكم في صلاحياته.

### 2. إدارة الدورات التعليمية (Courses Management)
- عرض قائمة الدورات المتاحة مع إمكانات فلترة حسب التصنيف، المستوى، السعر، والمدرب.
- عرض صفحة تفصيلية للدورة تتضمن الفيديوهات، الوصف، الأهداف، المحتوى، ومعلومات المدرب.
- الاشتراك في الدورات المدفوعة أو المجانية مع إدارة صلاحيات الوصول.
- تسجيل تقدم الطالب تلقائياً داخل كل دورة وتحديث مؤشرات الإنجاز.
- دعم وضع عدم الاتصال من خلال تحميل الفيديوهات مسبقاً عند بطء الإنترنت.

### 3. نظام عرض المحتوى (Content Delivery)
- تشغيل فيديوهات الدروس بجودات متعددة متكيفة مع سرعة الإنترنت.
- تفعيل قفل المحتوى (Auto Unlock) لعدم إتاحة الدرس التالي قبل إكمال السابق.
- دعم رفع وتشغيل ملفات PDF للاختبارات والأنشطة داخل الدورة.
- حماية المحتوى ومنع النسخ من خلال تشفير الفيديوهات وفرض سياسات الأمان.

### 4. نظام الدفع والاشتراكات (Payment System)
- دعم الدفع نقداً عبر مكاتب معتمدة وربطها بتأكيدات الإدارة.
- دعم التحويل المصرفي المحلي داخل ليبيا.
- تفعيل الدورة تلقائياً بعد تأكيد الدفع من الإدارة.
- عرض سجل عمليات الدفع لكل مستخدم مع تفاصيل الحالة والقنوات المستخدمة.

### 5. لوحة التحكم (Admin Dashboard)
- إضافة وتعديل وحذف الدورات مع إدارة المحتوى المرتبط.
- إدارة المستخدمين والمدربين ومراجعة صلاحياتهم.
- إدارة المدفوعات والتحويلات والتحقق منها قبل التفعيل.
- عرض تقارير تلقائية حول عدد المستخدمين، الدورات، المبيعات، والنشاط داخل المنصة.
- إرسال إشعارات للمستخدمين (تنبيهات، تحديثات، رسائل إدارية).

### 6. خصائص التفاعل (Engagement Features)
- نظام تعليقات داخل كل درس مع إشعارات وردود متسلسلة.
- إمكانية تقييم الدورة والمدرب وعرض متوسط التقييمات للزوار.
- إرسال إشعارات للتنبيهات، تقدم الدروس، والرسائل الإدارية عبر القنوات المناسبة.

### 7. البحث الذكي (Smart Search)
- البحث عن الدورات والمدربين والكلمات المفتاحية عبر محرك موحد.
- اقتراح دورات مشابهة بناءً على اهتمامات المستخدم وسلوك التصفح.
